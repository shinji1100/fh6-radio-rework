# Cockpit IR analysis

`cockpit_ir_metrics.csv` and `cockpit_ir_metrics.json` are generated by
`tools/analyze_cockpit_irs.py` from the 18 extracted multichannel PCM16 WAVs.

The radio reference uses ten unique four-channel responses whose channel
energy range is at most 10 dB. The eight-channel files are retained in the
profile but excluded from parameter fitting because their 58-81 dB channel
energy ranges indicate an unknown sparse convolution matrix. Without the
runtime event-to-IR mapping, the analysis describes response shape only and
does not label any file as engine, chassis, collision, or music.

The current real-time fit uses the robust early-reflection timing and decay
statistics. It deliberately does not copy the IRs' large low-frequency gain
onto full-range radio music.
